# 💡 灵感板 · 内容灵感收集 APP

把平时看到的**好标题、好选题、好案例、好钩子、好数据**随手记进来，按标签分类，写文案没灵感时一秒找到对标素材，实现素材的「丝滑参考」。

## ✨ 功能

- **清晰的侧边栏分类**：左侧自动生成 `好标题`、`好选题`、`好例子`、`好钩子`、`好数据` 五大分类，并实时显示每类数量。
- **极简添加流程**：右上角「＋ 添加」→ 粘贴内容 → 选类型 → 打标签 → 保存，几秒搞定。
- **标签分类与筛选**：每条灵感可加多个标签，顶部标签栏按热度排序，一键筛选。
- **全局搜索**：按内容 / 标签 / 来源即时搜索。
- **卡片管理**：每张卡片支持一键复制、编辑、删除。
- **本地保存**：数据存在浏览器 `localStorage`，无需登录、无需后端，刷新不丢失。
- **导出 / 导入备份**：左下角 `⬇` 一键导出 JSON 备份；`⬆` 导入恢复，换浏览器/设备也不怕丢；导入时可选择「合并」或「覆盖」。
- **深色模式**：左下角 `🌙 / ☀️` 一键切换，自动跟随系统偏好并记住你的选择。
- **快捷键**：`N` 快速新增 · `Esc` 关闭弹窗 · `⌘/Ctrl + Enter` 保存 · 标签输入支持回车 / 逗号分隔。

## 🌐 在线访问（GitHub Pages）

仓库已内置自动部署工作流（`.github/workflows/deploy.yml`）。推送到本分支后，GitHub Actions 会自动把站点发布到 GitHub Pages。

首次部署如果失败，到仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions** 即可（之后每次推送都会自动更新）。

部署成功后，访问地址形如：

```
https://<用户名>.github.io/<仓库名>/
```

在 Actions 运行日志或 Settings → Pages 页面可看到确切链接。

## 🚀 使用

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 📁 文件结构

```
index.html   页面结构
styles.css   样式（极简卡片风）
app.js       全部交互逻辑 + localStorage 存储
```

## 💾 数据说明

- 所有灵感保存在当前浏览器的 `localStorage`（key：`inspiration-board-items-v1`）。
- 首次打开会带几条示例数据，方便直观体验；删除后即为空板。
- 换浏览器或清除浏览器数据会导致灵感丢失，重要内容请自行备份。
